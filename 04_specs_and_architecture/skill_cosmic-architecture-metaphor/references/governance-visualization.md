## Visualization Sections

### 1. Overview Cards
Six top-level metrics: agents, skills, cron dirs, plugin dirs, gates, boundaries.

### 2. Boundary Lanes
Earth → Moon → Jhanos Gates → Pluto with write/read access rules and artifacts per zone.

### 3. Permission Matrix
Per-zone agent/user read/write permissions as a table.

### 4. Hard Constraints
6 rules with enforcement mechanism + 3-step violation policy.

### 5. Skills Inventory
61 skills across 17 categories as horizontal bars.

### 6. Agent Scaffolding Status
21 agents × 4 components (config/skills/cron/plugins) — 13 fully scaffolded, 8 partial.
